# DSN Masterclass Presentation Template

This directory contains the canonical specifications, design rules, and reusable templates for Data Science Nigeria (DSN) presentations and course portals.

## Files
- `SKILL.md`: Standard template rules and guidelines covering layout, typography, whitespace, shape borders, cover slide structure, and portal frame integration.

## Core Rules Summary
1. **Aspect Ratio:** 16:9 widescreen (`1280x720`).
2. **Top Pill Tags:** Strictly prohibited. No colored pill banners or category tags above titles.
3. **Card Borders:** No colored left borders or accent bars (`card-rose`, `card-blue`, etc.). Use uniform 1px solid `#e2e8f0`.
4. **Typography:** Compact and refined (`h2` at 20-21px, body `p`/`li` at 11.5-12px) to prevent awkward wraps.
5. **Whitespace:** Keep at least 50px-60px clearance above the signature DSN green/red bottom line.
6. **Cover Slide:** Clean title, subtitle in green, author and organization in two distinct lines directly beneath. No bulky descriptive blocks.
7. **Technical Notes:** Rendered via iframe preserving native styling, sticky TOC, and KaTeX equations.
8. **Sidebar:** GitHub repository link with official icon.
